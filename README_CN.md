# System Shell Box

## 这是什么？

**System Shell Box (SSB)** 是一个免费开源的文件管理工具，设计灵感来源于MT管理器，但完全基于终端模拟器实现核心功能。  
📦 本项目旨在为用户提供一个**轻量、可扩展**的MT管理器付费功能替代解决方案，无需依赖闭源功能。

**注意**: 此应用目前还处于早期，功能相当不完善
